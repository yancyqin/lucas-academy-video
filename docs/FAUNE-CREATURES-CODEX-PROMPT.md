**要做的**
1. **按画选，不用都加，也不用一个模版。**先看每幅画，判断这个场景里真的会有什么、在哪里：
   - 海边是远处的海鸥，草地是粉蝶，睡莲池是蜻蜓，罂粟坡是飘落的罂粟花瓣，树下是落下的花瓣。
   - 画里已经很满、很热闹的（比如蛙塘），可以什么都不加。
   - 12 幅里大概一半加生灵就够了。每幅最多两种，每种只放 1 到 5 只或片。
   - 同一种东西在不同画里也要不一样：物种、颜色、大小、飞法都跟着那幅画的季节、光线和风向。
2. **形状和笔触要像这幅画的一部分**，用代码画，不要用图片文件：
   - 画法：几笔短的、有方向的颜料笔触拼出来。颜色从画里取（用 `photo()` 取周围的颜色，再配上这幅画自己的调色，比如罂粟的朱红、莫奈的紫灰、雷诺阿的暖黄），带一点笔触的不规则。远看是画家随手点出来的，近看也不是一个干净的矢量图标。
   - 大小：要符合透视，远处的鸟只有几个像素长的一撇。
   - 蝴蝶要有两对翅膀，扇动时翅膀会开合（左右变窄再变宽）。
   - 蜻蜓：细长的身体，四片透明、会反光的翅膀。
   - 鸟：远看是一道弯弯的“V”，翅膀一扇一滑。
   - 花瓣：有正面、侧面，翻转时会变窄、变亮暗。
   - 可以扩展 `drawMark`，加新的 `shape`，但要让 `.lpp` 存下来的东西在 Studio 里也能打开（不认识的形状退回成 dot），并在 `docs/live-painting-editor-contract.md` 或 `docs/lpp-artlab-extension.md` 里写清楚。
3. **动起来要自然、要慢**：
   - 蝴蝶忽高忽低、走走停停，飘忽的路线，不是匀速直线。
   - 蜻蜓：悬停，然后突然一窜，再悬停。
   - 鸟：慢慢扇几下，然后滑翔，沿一条很长的弧线飞过天空。飞出画面后过一阵再从别处进来。
   - 花瓣：顺着这幅画的风向，一边翻一边飘落，到了下面淡出，再从上面（花丛或树上）重新出现。
   - 每一只、每一片的节奏都不同，不能同步。
4. **光斑、闪光：随机点几处，不排成行。**
   - 放在画里本来就亮的地方：水面的亮笔触、阳光照到的叶子和白裙。
   - 每幅只放几处，位置用种子随机，但要自然分散，不要格点、不要成行、不要均匀铺满。
   - 闪的节奏也各不相同：慢慢亮起、慢慢暗下。
   - 现在活层里已经有 `glint`（水面亮笔触的细碎闪烁）和 `dapple`（大片的叶间光斑），这次加的是少数几个更明显的点。
   - 不要每幅都加。已经够亮、够闪的画就不加。
5. **默认效果**：
   - 打开页面就能看到这些新东西。默认摆放用你为每幅画挑好的少数几个位置，或种子随机的几个点，**不要**用 `paintDefaults` 现在给 mark 画笔用的“之”字形成行涂法。
   - 「清除」清空，「默认效果」按钮重新摆一遍。
   - 孩子手动画的时候，一笔也不要冒出一大串：一笔只放一只或一片，或者按间隔很稀地放。
6. **孩子能读能改**：
   - 每个新画笔预设都很短，第一行注释说在模仿什么。
   - 代码是确定性的：不用 `Math.random`，用 `noise`、`rand`、`dist`、`TAU`、`photo()`。
   - 每支新画笔的中英文名字放在那幅画的 `brushes` 里，名字要贴合那幅画（比如「海鸥」「粉蝶」「飘落的罂粟花瓣」）。
7. **检查**：
   - `node --test tests/*.test.mjs` 必须全部通过（现在 392 个）。如果你给新形状或默认摆放加了测试，更好。
   - 浏览器里的视觉检查由我（Claude）来做：我会用 `window.__living.drawAt(t)` 逐帧渲染每幅画来看。所以请保证 `drawAt(t)` 只依赖 t、结果可重复。
   - 不要提交，不要部署。

**做完请告诉我**
- 每幅画加了什么、为什么、放在哪里（哪些画故意没加）。
- 新增或修改了哪些函数和画笔。

主人要的是“少而和谐”，**不是看不见**。下面的尺寸都按画布工作宽度 1440 px 算（parasol 是 1162 宽），页面上画布大约显示 1000 px 宽。

**每一样都要做到**：在正常页面大小、不放大的情况下，看几秒就能注意到它。同时它仍然是画里的笔触，不抢主体。

- **明暗对比**：和它当时身后的画面亮度差至少约 25%，或者颜色明显不同。
  - 路线和停留点要选在能衬出它的地方：白蝶飞在绿草上，不停在白花上；红花瓣飘到灰绿的田里，不在红花上。

  - 近景蝴蝶（meadow、path）30–44 px。
  - 远处海鸥 18–28 px：两三笔深蓝灰或白带灰影的弯 V，衬在淡天上要看得出。
  - 蜻蜓体长 34–46 px：深蓝绿的身体，玻璃一样会闪的翅膀，放在淡紫的天空倒影上。
  - 罂粟花瓣 14–22 px。
  - 春天的落瓣 12–18 px，淡粉或白，从树冠往下落，穿过深绿的树荫，衬得出来。
- **动的范围要大一些**：
  - 蝴蝶在 150–400 px 的范围里飘忽飞，偶尔落在花上 1–3 秒，翅膀慢慢开合，再飞走。

  - 海鸥沿长弧线慢慢横过天空，一次大约 20–40 秒，飞出画面后过一会儿从另一边回来。可以被松树挡住。
  - 花瓣顺风翻落，横向漂移明显，落到下面淡出，再从花丛或树上重新出现。
- **光斑、闪光**：
  - 每一处是一次清楚的星点：亮到接近白，10–18 px，带短的十字或一道细光，外面一圈柔光。
  - 1.5–3 秒亮起再暗下，之间停很久，每处节奏不同。
  - 任何时刻一幅画里只亮 1–2 处。位置仍然随机分散、不成行，放在画里本来就亮的水面、叶尖和白裙上。

Claude 做的 warp、风、阳伞、区域和着色器都**不要动**。

1. **蝴蝶改成印象派的画法**（草地、小径、日本桥的蝴蝶都改）。
   - 问题：现在的蝴蝶是对称、轮廓清楚的剪影，中间一根深色身体棍，像贴纸，所以“假”。
   - 要求：像莫奈、西斯莱、雷诺阿画花那样，用几笔松散、断开的颜料点**暗示**一只蝴蝶：
     - 每只由 4–8 个短促的色点和笔触组成，颜色不止一种：
       - 白蝶是暖白，加一点淡紫或淡蓝的阴影点，再带一点身边草地的反光绿；
       - 黄蝶是柠檬黄加赭黄，再一点橙。
     - 没有描边，没有清楚的翅膀轮廓。身体最多是一个很小的暗点，或者干脆没有。
     - 左右不完全对称，笔触的位置、长短每帧略有变化，像颜料在颤。
     - 扇翅时用笔触的伸缩和轻微拖影来表现，不是一个剪影在开合。
     - 边缘的色点可以半透明、融进背景，但中心要够亮够实，正常页面大小下几秒内能看出“那是一只蝴蝶在飞”。
     - 远看像蝴蝶，近看是颜料。
   - 蜻蜓现在可以接受，可以顺手让它也少一点“图标感”，但不是重点。
2. **草地的两只菜粉蝶，轨迹要明显不同**：
   - 一只贴着草尖低飞，之字形一跳一跳，常落在花上停一停；
   - 另一只飞得高一些，画大而慢的弧线和圈，很少停；
   - 速度、范围、停留的节奏都不同，活动区域也错开。
   - 其他画里成对的蝴蝶也同样检查：不能像同一条轨迹的复制。
3. **昂蒂布的海鸥：各自在自己的区域里飞**：
   - 不要横穿整个画面，也不要飞到松树后面被挡住（去掉遮挡的做法）。
   - 给每只一个开阔天空里的小区域：
     - 一只在左边松冠下和远山之间的天空；
     - 一只在右边，海面上方或远山上方的天空。
   - 在区域里慢慢盘旋、滑翔、偶尔扇几下翅，一直看得见。
4. **塞纳河的白星点：多一些、稀疏一些**：
   - 水面上的亮处找 6–8 个点。随机分散，彼此离得远，不成行、不成团。
   - 同时最多亮 2 处，此起彼伏，亮灭节奏各不相同。
   - 星点的样子保持现在这样，主人认可。
5. **日本桥：闪的多一些**：
   - 除了岸边叶尖的光，在睡莲池的水面亮处也加一些水光星点，像塞纳河那样的近白小星。
   - 总共大约 6–9 处，随机分散。
   - 同时可以亮 2–3 处，闪得比现在频繁。
6. **罂粟花瓣多一些**：从 3 片增加到大约 7–9 片。
   - 每片大小、红色深浅、翻转和漂移都不同。
   - 从坡上不同的花丛起飞，顺风飘到灰绿的田里，避开人物。
7. **春天的淡粉花瓣多一些**：从 3 片增加到大约 7–9 片。
   - 从树冠不同位置落下，穿过树荫，每片轨迹、大小、颜色深浅都不同。
8. 前几轮的要求继续有效：
   - 看得见；
   - 颜色出生时定下；
   - 每只不同、有随机性；
   - 确定性（只依赖 t 和种子）；
   - 测试全过；
   - 不提交，不部署。
