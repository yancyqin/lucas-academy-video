**在哪里改**

**现在的机制（可以改，也可以推翻重做）**
画笔是给孩子看、给孩子改的代码：`warp(x, y, t)`，x、y 是像素，t 是秒，可以用 `noise`、`rand`、`dist`、`TAU`。返回值里每一项都可以不写：
- `dx`、`dy`：这里的画面挪几个像素
- `light`：-0.5 到 0.5，变亮或变暗（用宽羽化，不会出现方块或圆盘）
- `glint`：0 到 1，亮的笔触闪烁（水面的阳光）
- `flowX`、`flowY`：每秒几个像素，画面朝这个方向一直流（两份画面错开半个周期交替淡入淡出，周期 3 秒）
- `shiver`：0 到 1，细碎的快速颤动（树叶沙沙、热气）
- `ripple`：0 到 1，细横线状的摇晃（水里的倒影）

着色器负责逐像素的细节（shiver、ripple、glint 和 flow 循环）；画笔只在网格点上算，所以画笔里噪声的空间频率要低（周期不小于约 60 像素），否则会出现格子。

**“像”是什么意思**
- 静水的倒影：沿水平细线轻轻错动，很慢；整体不要像果冻一样晃。
- 池塘：小涟漪经过，睡莲叶子微微漂，亮处偶尔闪一下。
- 碎光的水面（蛙塘）：水波一段一段地断开又合上，阳光在波峰上闪。
- 海：涌浪一排排朝观众推过来，越近越快越大，浪尖上有闪光；远处几乎不动。
- 云：慢慢飘、慢慢变形，亮暗缓缓变化；后面的树和山不能被云带着走。
- 雾：是一层飘过去的淡色纱，不能拖着后面的树一起动。
- 树：大枝慢慢摇，叶团轻轻抖，衬着天空的树冠边缘会闪动；树干基本不动。
- 草地：一阵风像一道浪从田里扫过去，草被压弯、颜色变浅，风过去后再弹回来。
- 花：在风里点头，一下一下的，不是整片一起平移。
- 裙子、面纱：被风一阵阵吹起的波浪。
- 叶间光斑：亮斑在地上和衣服上慢慢游走。
- 热气：远山上方的空气在细细地抖。

**绝对不要**
- 印章一样重复的点、圆、笔刷图案（上一版就是这样被否掉的）。
- 看得出边界的方块、圆盘、直线（羽化要够宽，边缘要自然）。
- 该静止的东西在动：人物、脸、桥、栏杆、船、树干、房子、悬崖的轮廓。如果某个区域里有它们，就把区域切开，绕过去（参考 `faune-antibes` 海浪用 `poly` 绕开树干，`faune-poppies` 风绕开人物）。
- 所有画都用同一种动法。
- 新增或替换画作。不要任何牧神题材的画，不要裸体。只做下表 12 幅。
