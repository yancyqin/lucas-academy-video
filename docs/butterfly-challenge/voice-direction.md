# Challenge 猜一猜哪些蝴蝶是真的？· 配音演绎稿（中文）

这份稿子只管**怎么读**；字幕永远用 [zh-edit.md](zh-edit.md) 的定稿原文。规则见 SCRIPT-AND-VOICE.md（2026-10-24）第 4、5 节。

**通读后的判断。** 全片是 Yancy 带着观众玩一个猜谜游戏，轻松、好奇、有一点点调皮。没有哪一段情绪真的变了，所以全片只用一个读法，不换语气指令：

- 片头：把规则讲清楚，「你来猜」那句真的在问观众。
- 公布时的几句：带一点笑，像在说「哈，又上当了」，不是在嘲笑 AI。
- 讲蝴蝶的句子：像在跟家里人介绍一个刚认识的小动物，事实说清楚，不念成百科。
- 结尾：轻轻收住。

**基准（试音时定，见下面「试音」）**

- 声音 `yancy/zh`，`zero-shot-instruct`，陈述句语速 1.2，问句 1.1（「跨越中等收入陷阱」「你爱听 AI 说是的吗」都是这个配置）。另试 `louise/zh` 1.1 做对比。
- 语气指令：「请用轻松、温暖、好奇的语气，像跟朋友、跟家长一起玩猜谜游戏那样说。」指令里不写任何「慢」字。

**标记**

- `<strong>词</strong>` 是重音，只标对比词和关键词。
- 标点只加不改：`……` 停一下，`！` 提气，`？` 上扬。
- `停顿 N` 是这句前面的安静秒数（同一段里的下一句）；段和段之间的时间由画面定（配对图 3 秒、公布、视频）。默认句间 0.45 秒。
- `读 |` 是实际念的字，只在和字幕不同时才写。

**容易读错的地方（试音和全片都要用 Whisper 查）**

- 量词「对」：Yancy 听着发音有问题（2026-11-12），全片改用「组」；「对了五对」改成「猜中了五组」。
- 量词「只」（zhī）：「一只是真的」「哪只是真的」容易被读成「只是」（zhǐ shì）。凡是量词「只」，念的字都换成同音的「枝」。「只住在」「只能看图」的「只」是 zhǐ，不换。
- 「长得很像」的「长」是 zhǎng，念「掌」；「比大多数蝴蝶长得多」的「长」是 cháng，念「常」。
- 「莳萝」念「时萝」；「新几内亚」的「几」是 jǐ，念「新己内亚」。
- 「蛱」是 jiá（蛱蝶），没有好替换的字，配完单独查。
- 数字和英文：「GPT-6-Astra」念「GPT 六 Astra」；「Claude Fable 5.2」念「Claude Fable 五点二」；「8」字斑念「八」字斑。英文名配完要单独听。
