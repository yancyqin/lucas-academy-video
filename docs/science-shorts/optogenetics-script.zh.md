# 光怎么帮他找到桌上的东西？



**o01** 一位失明的人，怎么又找到了桌上的笔记本？

**o02** 线索，竟然藏在绿藻里。光一照，它们就朝着光游过去。

**o03** 科学家找到了会被光打开的门。装进别的细胞，光就能让它发出信号。

**o04** 这位病人的感光细胞坏了，后面传信的细胞，却还在。

**o05** 研究团队给那些细胞装上另一种光开关。琥珀色的光，就能把它打开。

**o06** 特制眼镜把明暗变化，变成一闪一闪的光点。这叫编码。

**o07** 大脑再学着把光信号读成东西的样子。这叫解码。

**o08** 练了几个月，他能找到一些物体，还能伸手去摸。

**o09** 这是一位病人的部分恢复。他仍需要眼镜，也没恢复正常视力。

**o10** 从一个光信号开始，我们能一点点研究大脑怎样处理信息。

**o11** 在 Lucas Academy，我们一起一点点探索：大脑如何思考，AI 又如何学习？
