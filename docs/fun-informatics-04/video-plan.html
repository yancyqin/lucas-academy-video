实拍（备选）

11-01：先用 Muse 生成，不买培养液。生成的不满意，再考虑下面的实拍。

镜头拍什么怎么拍
S08家里的电灯开关，按两下手机横拍，特写开关和手，灯亮灯灭各一次。拍不了就用 Pexels。
S39白桌上一个笔记本、一个小盒子，一只手慢慢伸过去摸到笔记本俯拍或 45° 斜拍，背景干净。只拍手，不露脸。
S31一台相机连着线家里有就拍 5 秒，没有就用 Codex 图。
S01 / S03 / S47一碟衣藻（或眼虫）培养液，手电从一边照，绿色往光那边挪要先买培养液：Carolina Biological Supply（item 152041）或 Ward's Science 都有莱茵衣藻。放在白色浅碟里，暗室、手电从侧面照，固定机位拍 5–10 分钟再加速。

Codex 图与自己做的动画

Codex 图（我来跑）

  • Muse 首帧（11-01 已生成）：dish-green、dish-beam、goggles、notebook-table、camera-cable、chlamydomonas，脚本 scripts/fun-informatics-04/images.py。
  • 眼睛剖面：光进来、视网膜、视杆视锥、后面接力的细胞、视神经。写实风，不带字，字由动画加。
  • 一道「光控门」：细胞表面的一道门，光一照打开。和诺贝尔插图的风格靠近。
  • 相机：里面感光的那一块坏了，连到电脑的线是好的（S31 没实拍时用）。
  • 香农通信图的图标：世界 → 眼镜 → 光点 → 新开关 → 大脑（接第二期的香农）。
  • 备用：克里克「神经细胞开关」的梦想图（诺贝尔科普 PDF 图 1 许可不清楚时重画）。

动画（Remotion，我来做）

  • 片名卡、章节卡、经文卡（和合本）、结尾卡。
  • 神经信号对照开关：每次一样高的信号 ↔ 0 / 1 的灯；同样的信号疏密不同。
  • 半毫秒 vs 十毫秒的两条时间条。
  • 光控门打开、带电小颗粒流进去；不同细胞装上门以后都会亮。
  • 光照亮一片，只有装了开关的细胞响应。
  • 眼睛里光开关一个个暗掉；给接力细胞装上新开关；琥珀色代替蓝色。
  • 编码 → 解码的链条；笔记本 36 / 39 的计数；「一位病人 · 部分恢复 · 要戴眼镜 · 临床试验中」字卡。
