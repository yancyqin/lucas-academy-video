**通读后的判断。** 全片是一个人带着观众一边看、一边想，大部分用同一个读法：亲切、好奇，像发现一件有意思的事。情绪真的变了的地方才换：

- 问观众的句子（字幕以「？」结尾）用「好奇」，问完至少安静 1.2 秒，让人想一想。读得像一起琢磨，不能像考问。
- OG05 讲那位病人，平实、真诚，不煽情；og05-11 的提醒清楚、不打折扣，仍用基准。
- OG06 讲圣经里的光，换「温和」；经文平实地念，不拿腔调。最后两句（订阅、留言）回到基准，轻快一点。

**基准**

- 声音和语速等试音定：候选 `louise/zh` 1.1、`fangfang/zh` 1.2 或 1.3，`zero-shot-instruct`，全片一个语速。
- 语气指令（指令里不写「慢」）：
  - 基准：「请用亲切、好奇的语气，像跟朋友、跟家长一起发现一件有意思的事那样说。」
  - 好奇：「请用好奇、温暖的语气，像在和朋友一起琢磨一个问题，不是在考问。」
  - 温和：「请用温和、真诚的语气，像在安静地分享一段心里的话。」

**标记**

- 小节标题的 `｜语气 X` 是这一节的默认语气；句子后面的 `｜语气 X` 只改这一句。
- `<strong>词</strong>` 是重音，只标对比词和关键词。
- 标点只加不改：`……` 停一下，`！` 提气，`？` 上扬。
- `停顿 N` 是这句前面的安静秒数。默认句间 0.45 秒，小节开头 1.5 秒，问句之后至少 1.2 秒。
- `读 |` 是实际念的字，只在和字幕不同时才写：数字写成汉字，零写「零」；「」换成“”；外国人名去掉中间的点；
  多音字换成只有一个读音的字：长出 → 掌出（zhǎng），摸中 → 摸众（zhòng）；「得有」改成「要有」，免得读成 dé。
