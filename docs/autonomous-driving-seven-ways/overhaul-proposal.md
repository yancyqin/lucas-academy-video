# 《自动驾驶与七种思维方式》大改建议（2026-11-11）

## 为什么现在这版不吸引人

按影响大小排：

1. **标题说的是自动驾驶，第一个路面镜头却到 1:43 才出现。** 前面是素材片段、七个名称卡和乐高。上一版（v8）在 0:17 就进雨夜路况，这版反而往后挪了。
2. **开头是道理，不是事。** 0:00–0:44 一连八个问题，一个都没回答，也没有任何事情发生。破题那三问更适合放在片尾，当作想一想的话。
3. **它是一堂分类课。** 「这就是……思维」出现了十来次。线性、发散、综合在乐高里讲一遍，到路上又讲一遍。每一段都是同一个套路：放画面、解释、贴标签。看到第三分钟，观众已经能猜出下一句。
4. **没有风险，也没有意外。** 每一段的结果都是「等」或「减速」。唯一一件真事（落叶让卡车急刹车）放在 5:50，只讲了 38 秒。
5. **声音里没有人。** 旁白是 Louise 中性的「我们」口吻，不符合 10-24 定的标准：Yancy 第一人称，从一件真事讲起。路况那段旁白是 AI 起草的，AI 味重。
6. **节奏和画面都散。**
   - 好几段开头，一句短话撑 9–10 秒。
   - 素材片、米色乐高、HUD、油画四种画风来回切。
   - HUD 上的小字根本看不清。
7. **片尾和正片接不上。** 雾海上的旅人和自动驾驶没有关系，接着就是「点赞订阅」。
8. **片名像课程大纲。** 「七种」先许诺了一张清单。

（Fable 审片的结论和以上基本一致。）

## 已核实的真事（AWARD D7.3 影响评估报告，2.0 版，2024-07-10）

奥地利 Gunskirchen，KAMAG 无人驾驶电动卡车，在 BRP-Rotax 工厂和 DB Schenker 之间约 600 米的公路上往返送货。主路很窄，最高只开约 25 km/h。

| 事实 | 出处 |
|---|---|
| 紧急制动太灵敏，常为落叶这类小东西急刹，车上的货因此移位 | §4.8.1 |
| 急刹次数最多是人类司机在同一路线上的 11 倍；下雨更严重；突然停车可能让后车差点追尾 | §4.8.2 |
| 2023-08-07 到 09-20，共 7.9 小时实际行驶，记录 47 次停车：13 次因为其他车辆，12 次定位丢失，9 次天气，其余是安全停车、靠近路径的障碍物等，平均十分钟一次 | §4.8.2 |
| 同一辆车却看不见一块只有 14.4 厘米高的欧标托盘，报告建议加摄像头做数据融合 | §4.8.2 |
| 路边树木、植被一变，激光雷达定位就会出问题 | §4.8.1、§4.8.2 |
| 有的司机在红灯前等了 30 秒，看没动静就闯过去了 | §4.8.2 |
| 频繁刹车让耗电增加约 20% | §4.8.4 |
| 同项目的无人叉车，开发者打算把树叶、树枝这类软障碍物归为「不是障碍物」 | §5.8.2.1 |

## 推荐方案 A：《一片落叶，为什么让卡车急刹车？》（约 4 分钟）

一件真事从头追到尾。思维方式不再一个个贴标签，而是破案时自然用上的几步。你的主旨「最前沿的工程，也要分解成不同的思维方式相互补充」正好是这个案子的答案。

| 时间 | 内容 | 画面 |
|---|---|---|
| 0:00–0:15 | 奥地利，一辆没有司机的卡车在乡间路上来回送货。路上什么都没有，它突然一脚急刹，车上的货一下子移了位。罪魁祸首是几片落叶。 | 情景重现：已有卡车镜头 + 新做落叶、货物移位 |
| 0:15–0:35 | 它急刹的次数最多是人类司机的 11 倍。可同一辆车，却看不见路上一块 14 厘米高的木托盘。太敏感，又太迟钝，换你，会先从哪里下手？ | 数字动画；新做托盘镜头 |
| 0:35–1:15 | 别急着猜：先把可能的原因都列出来，再看记录。47 次停车分成几类。（发散，再看证据） | 47 次停车柱状图动画 |
| 1:15–2:05 | 我们来设想一个测试：行人和落叶同时出现，车停了。先只去掉落叶，再只去掉行人，每次只改一个条件。观众先猜结果。 | 已有过街片段 + 模拟动画，画面标「设想」 |
| 2:05–2:45 | 一脚急刹，影响的不只是自己：后车差点追尾，货物移位，还更费电。 | 已有后车、HUD 素材 + 新做后车镜头 |
| 2:45–3:30 | 真正难的是取舍：落叶可以不管，托盘和孩子绝不能漏。先定目标，再倒推要分清什么；判断每种情况有多可能；几种考虑放在一起做决定。工程师的办法：把落叶、树枝归为「不是障碍」，再加摄像头补看低矮的东西。 | HUD、对比画面 |
| 3:30–4:00 | 回到家里：纸飞机飞不远，问题出在哪里？钥匙找不到，先想想上次是什么时候用的？（你的原句）再前沿的工程，也是把大问题拆开，让几种思维方式互相补充。 | 已有纸飞机、钥匙片段 |
| 结尾 | 用你的破题问题，或者你写的那段结尾话，二选一；也可以什么都不加。 | — |

## 备选

- **B《绿灯亮了，为什么不走？》**：一个路口放慢看三遍，每遍观众先下注再揭晓。风险是用的三段素材和《决策树与神经网络》一样。
- **C 第一人称随笔**：从你想教孩子怎么想问题讲起。只有你有真实的那一刻才成立；你写的破题和雾海结尾在这一版里最合适。
- **系列化**：「七种思维」改成七集短片，每集一个真实小案子，一种思维讲透。

## 风险

- 行人加落叶的「只改一个条件」测试是我们设想的，不是 AWARD 做的。画面和旁白都要说「我们来设想」。
- 路况镜头是 AI 生成的拟真视频，卡车是情景重现。画面上标「AI 生成 / 情景重现」，上传时勾选合成内容。
- 「发散 / 批判」这些说法只是类比，真实系统不是按这些类别搭的。说一句就够。
