# 怎么骗过 AI：面包还是狗？· 配音演绎稿（中文）

这份稿子只管**怎么读**；字幕永远用 [zh-edit.md](zh-edit.md) 的定稿原文。规则见 SCRIPT-AND-VOICE.md 第 4、5 节。

**通读后的判断（v0.4）。** 全片是 Yancy 带着大家做一个好玩的小实验：以前这是道难题 → 现在想办法骗 AI → 为什么现在难骗。轻松、带笑、有点调皮，节奏要快。情绪变两处：sc02-08 问观众「被骗了还是在陪我玩」，读得好奇，真心想听对方怎么想；结尾 sc05 讲道理，像跟家长解释一件有意思的事，不念成课本。其他句子都用基准读法。

- 片头：「狗，还是面包？」是一个俏皮的问题；讲 2017、2019 的研究像讲两个好笑的小故事（泰迪熊、狗鼻子、换了大象皮的猫）。
- 每招开头「第 N 招」：轻快地起一个头。
- 揭晓的句子（sc01-04「其实是一个蛋糕」、sc03-02「百分之百是法棍」、sc04-02「面包，百分之九十九」）：前面顿一下，带笑。
- 引 AI 原话（「它说：……」）：冒号后面顿一下，原话读得像在转述一句好笑的话。

**基准**

- 声音 `louise/zh`，`zero-shot-instruct`，语速 1.1（Yancy 2026-11-16「Louise 1.1」）；英文音轨 `louise/en` 1.1。
- 语气指令：「请用轻松、温暖、有点俏皮的语气，像跟朋友、跟家长分享一个好玩的小实验。」指令里不写「慢」。

**标记**

- `<strong>词</strong>` 是重音，只标对比词和关键词。
- 标点只加不改：`……` 停一下，`！` 提气，`？` 上扬。
- `停顿 N` 是这句前面的安静秒数（同一段里的下一句）；默认 0.45 秒。
- `读 |` 是实际念的字，只在和字幕不同时才写。

**容易读错的地方（配完都用 Whisper 查）**

- 量词「只」（zhī）：「这只」「一只」容易被读成 zhǐ，念的字换成同音的「枝」（蝴蝶片的做法）。
- 数字：「2015 年」念「二零一五年」，「2017」「2019」「2021」同样（零不写〇）。
- 英文名：LLaVA 念 Lava，ResNet、CLIP、Astra、Transformer、AI 照英文读；配完单独听。
- 「卷」（肉桂卷）是 juǎn；「撒了面粉」的「撒」（sǎ）；「松饼」。
- Louise 的中文有时把「……」念成「嗯」（v1 的 sc02-03、sc02-09），新句子少用「……」，用逗号、冒号。
- v1 里「法棍」第一次像「法官」，「贴」像「添」，改标点重配过；沿用的句子用的就是那几条。
