**4 套风格（每套跟一位画家的笔法）**
1. `monet`：莫奈。短而断开的笔触，颜色并置（紫、蓝、粉、黄绿），光感强，阴影是彩色的。
2. `sisley`：西斯莱。柔和的小点和短笔，色调清淡，蓝绿和暖灰，安静。
3. `morisot`：莫里索。快速、轻盈的之字形长笔触，留白多，像速写，银白、淡蓝、淡粉。
4. `renoir`：雷诺阿。羽毛一样柔软的暖色笔触，奶油、桃红、金黄，边缘融化。

**每套 3 张，文件名 `<风格>-easel.png`、`<风格>-brush.png`、`<风格>-wand.png`**
- **画架**：19 世纪木制写生画架，上面架着一块**空白画布**。画布是一块明亮的米白色长方形，四边要清楚（我要自动找到画布的四个角，把画贴上去）。三分之四侧面，画布正面朝观众，向右转 15–20°，宽略大于高。画架下层可以有调色板。
- **画笔**：一支旧油画笔，长木柄、金属箍、笔头蘸着颜料。斜放，**笔尖朝左下，约 45°**，笔尖要清楚。
- **魔法棒**：一根维多利亚风格的魔法棒，深色木杆、金属环、顶端一颗水晶或小星。斜放，**顶端朝左上，约 45°**，顶端要清楚。不要画光晕。
- **背景必须是纯色洋红 #FF00FF，完全平整**，没有阴影、没有渐变（印象派里常有绿色，所以不用绿幕）。物体完整入画，四周留洋红边距。物体里不要出现洋红色。
- 不要文字和签名。尽量高分辨率（画架竖幅 1024×1536，画笔、魔法棒正方形 1024×1024 或更大）。
