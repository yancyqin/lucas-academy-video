## 03 · 光子隧道

| 时间 | 镜头 |

## 推荐组合

以 01 深空隔舱作为世界观，借 03 的管内追光视角做最前面的 0.5–1 秒，再拉出两座太空舱，切到纸条被管口挡住。镜头先让观众看清角色想做什么、哪里卡住，再进入零和一的约定。02 的城市雨夜可作为另一套完整世界观。

后续制作应同步改写 S1 中英文的树屋叙述、角色动作、镜头与音效。v1 的树屋画面不能当作这轮风格已落实的成片。动作样片因 Muse 视频服务不可用而未生成。服务恢复后，需要把两张参考图都实际上传给 Muse，再下载生成原件并在本地合成；Muse 不能读取 Mac 路径。得到实际片段后才记录时长、SHA256 和动作审核结果。
