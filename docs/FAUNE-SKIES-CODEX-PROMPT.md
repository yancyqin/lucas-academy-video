**每幅输出 2 张**
1. `clean-<名字>.png`：和 `sky-<名字>.png` **同样大小**。把挡住天空的东西（树、岩石、人物、伞、草）都去掉，换成延续周围的天空和云，用同样的笔触和颜色。原来就是天空的地方尽量不变。
2. `wide-<名字>.png`：**只有天空**的长条。高度和 `sky-<名字>.png` 一样，**宽度至少是它的 3 倍**。
   - 最右边一段（宽度等于原图）就是 `clean-<名字>.png`。
   - 向左延伸出新的天空：新的云、同样的画家笔法、同样的颜色和光线、同样的透视（靠下沿的云更小更扁、更淡）。
   - 新的云不要重复原图里的云，也不要和原图一样的排列。
   - **左右两端要能无缝循环**：最左边的边缘要能自然接上最右边的边缘，接起来看不出缝。
   - 图像工具一次画不了这么宽，可以分几张生成，每张用前一张的边缘做参考，再用 Python 拼起来，接缝处做柔和过渡。
- 要一眼看得出是同一位画家画的油画天空，有笔触和颜料的感觉，不要照片感，不要 AI 光滑感。
- 不要文字和签名。

**自己检查**：
- `clean` 和原图并排看：天空部分有没有变样？挡住的东西是不是干净地去掉了？
- `wide` 里有没有接缝、重复的云？把最右端和最左端拼起来看能不能无缝循环？
- 不满意就重做。
