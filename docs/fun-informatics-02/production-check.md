## 制作时必须对齐的细节

1. **cl03-03 到 cl03-07 猜字。** 本轮中文版上英文、下中文：上屏 `wor__` 分两步补 l、d，
   下屏「神爱世＿」的按钮对应「界、代、上、人」，每次只选择一个字符。文案已经去掉四个完整词的猜法。
   实际录屏已核对：线上把「神爱世人」当四字词，干扰项取其他四字词末字，不能得到「界、代、上、人」。本轮保留定稿，这一步采用标注「教学示意」的局部卡；其他过程为真实录屏。
   香农的原实验按连续文字猜下一个字母；应用先露出词首再逐个补词尾，是受其启发的简化。

2. **cl03-08 陌生经文。** 固定脚本随机选择只是在演示试错，应标「模拟试错」。
   一次猜中百分比不是香农定义的冗余率；片中的英文「约一半」是历史估计，不能由本次四选一结果计算出来。
3. **cl04-04 到 cl04-08 猜词与训练类比。** 从逐字补全转到整词选择，cl04-05 后留 12–18 秒音乐停顿，
   实际跟玩 3–4 步，至少一处先错再对。台词已说明训练候选远不止四个，且用概率大小解释意外。
   真实模型预测下一个 token，候选来自词表，token 也不一定是完整的词。配教学卡注明「四选一为教学简化」。
   交叉熵看的是实际 token 获得的概率：概率越高，意外越小；不能只画成对/错二值计分。
4. **cl04-11 注意力。** 指向小红的粗线是帮助理解的示意，不宣称测量过 Claude 的实际注意力。
5. **cl04-16 候选选择。** 柱状图应展示概率；模型生成可以采样，并非每次必选最高概率项。
6. **片尾停留。** 四个问题按朗读顺序逐个出现，末尾回到一起学习、一起思考，池塘调暗但仍可见。结束卡无新增旁白，
   保证 cl07-01 仍是最后一句；扫黑帧时也要检查淡出和文字背景。

## 事实核查资料

- [Shannon, A Mathematical Theory of Communication（1948）](https://worrydream.com/refs/Shannon_1948_-_A_Mathematical_Theory_of_Communication.pdf)：
  冗余、英文约一半的历史估计、词统计生成和填字游戏。猜下一个字母的专门实验另见 1951 年论文；
  本次应用示范不是复现实验或测量。
- [Vaswani 等, Attention Is All You Need（2017）](https://arxiv.org/html/1706.03762v7)：
  注意力与下一 token 的概率分布，尤其第 3.2、3.4 节。
- [Anthropic, Tracing the thoughts of a large language model（2025）](https://www.anthropic.com/news/tracing-thoughts-language-model)：
  模型逐步生成与内部计算的区别；不能把教学连线当成真实模型解释。
- [Singhal 等, A Long Way to Go: Investigating Length Correlations in RLHF](https://arxiv.org/abs/2310.03716)：
  部分偏好训练中存在长度偏差；不能据此宣称所有 AI 一律奖励长答案。
