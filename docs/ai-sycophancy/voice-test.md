# 你爱听 AI 说「是的」吗？· 试音（中文）

整片怎么读见 [voice-direction.md](voice-direction.md)；这里是选声音、选语速时配的九句。

Yancy：「语言用 fangfang 先测试一下 1.3 倍速，要有感情。我听听，也用 Yancy 1.2 倍速听听吧。先找几句试试。」

- 两个声音读同样的九句、用同样的语气指令，只有声音和语速不同：`fangfang/zh` 1.3，`yancy/zh` 1.2。都用 `zero-shot-instruct`。问句这次也用同一个语速（上一期 Yancy 的问句是 1.1）。
- 九句挑的是不同的情绪：开头的轻松（sc00-01、02）、转折（sc00-03）、讲她小时候（sc01-04、10）、最沉的一句（sc01-19）、和观众互动的问句（sc03-08）、送给观众的那句话（sc06-04）、片尾（sc07-14）。
- 语气指令（指令里不写「慢」）：
  - 基准：「请用真诚、温暖、有感情的语气，像跟朋友、跟家长聊天那样说。」
  - 凝重：「请用真诚、凝重一点的语气，像在讲一段让人心疼的往事。」
  - 温和：「请用温和、真诚、带着希望的语气。」
- 标记：`<strong>` 是重音；`读 |` 是实际念的字（数字写成汉字，「」换成“”）。

sc00-01 ｜基准｜带一点笑，像在说一个大家都碰到过的小事
  读 | 你有没有发现，你问 AI 一个问题，它常常会先夸你一句：“这是个<strong>好问题</strong>！”“你说得<strong>对</strong>！”
sc00-02 ｜基准｜前半句承认，后半句真的在问观众
  读 | 说实话，被认同的感觉，挺好的。你<strong>爱听</strong> AI 说“是的”吗？
sc00-03 ｜基准｜语气转，轻一点、认真一点
  读 | 可是，如果在你<strong>最需要</strong>有人拦一拦的时候，它也只会说“是的”呢？
sc01-04 ｜基准｜讲故事，温暖，「一遍，再一遍」有节奏
  读 | 七岁起，她就坐在家里客厅的电脑前，放进爸爸给她买的英语光盘：听一句，跟读一句。一遍，再一遍，软件测试过关了，才往下学。
sc01-10 ｜基准｜郑重地请观众记住
  读 | 请大家记住这件事：丢掉的词，她<strong>自己找回来过一次</strong>。
sc01-19 ｜凝重｜全片最沉的一句，不煽情
  读 | 二月七号晚上，她和爸爸打了四十分钟电话。快挂电话的时候，她突然失神了两分钟：听得见爸爸的<strong>声音</strong>，却听不懂他在说什么；后来听懂了，却<strong>说不出话</strong>。她不想让爸爸担心。
sc03-08 ｜基准｜好奇地问，问完留白
  读 | 大家有没有发现，她的这些问题，有一个<strong>共同点</strong>？
sc06-04 ｜温和｜像送一件小礼物，引号里那句放慢、清楚
  读 | 所以，我想送给大家一句话。下次你带着自己的想法去问 AI，在问题后面加上一句：“如果不是，请<strong>诚实</strong>回答我。”
  （引号里的「……」不念：Yancy 那一条在那个位置多出一个「哼」，重配时去掉了。fangfang 那条是带「……」配的，没有多出声音，留着。）
sc07-14 ｜温和｜片尾，轻，收住
  读 | 愿她安息。也愿我们每个人，在最难的时候，身边都有一个会说“等一等”的人；也愿我们，能做别人身边那个人。

**试音结果（10-30）**
- 试听：`out/ai-sycophancy/voice-test/fangfang-1.3.mp3` 和 `yancy-1.2.mp3`，九句连在一起，句间 0.8 秒，各约 84 秒。单句在 `lucas-academy-media/outputs/{fangfang,yancy}/zh/ai-sycophancy-test/`。
- 两个声音的实际语速几乎一样：fangfang 1.3 是 4.21 字/秒，Yancy 1.2 是 4.26 字/秒。
- Whisper 查过，字都对。几处要注意：
  - fangfang sc00-02 在「你爱听」前面自己加了一声「嗯」，像在想。
  - Yancy sc06-04 原来多出一个「哼」，已经重配。
  - sc00-03 的「拦一拦」，两个声音的 Whisper 都听成过「来一来」；强制解码三条都是「拦一拦」占优，但差得很少。如果听着像「来」，可以把稿子改成「有人拦你一下」。

**加试 Louise（10-30）**：Yancy：「用 Louise 试试，中文……语气指令感觉可以。1.0、1.1、1.2 语速都试试。」`louise/zh`，同样九句、同样三种语气指令（不用她原来的默认指令「好奇、慢慢探索」）。
- 试听：`out/ai-sycophancy/voice-test/louise-1.0.mp3`、`louise-1.1.mp3`、`louise-1.2.mp3`。
- 实际语速：1.0 是 3.57 字/秒（91 秒）；1.1 是 3.93 字/秒（83 秒）；1.2 是 4.26 字/秒（76 秒），和 fangfang 1.3、Yancy 1.2 一样快。
- Whisper 查过，字都对。1.2 那条片尾（sc07-14）的「也愿」原来含糊，强制解码「也」只比「点」高 0.2，已经重配，现在高 12.2。「拦一拦」照样被 Whisper 听成「来一来」，三个声音都一样。

**定下来（10-30）**：Yancy 选了 **Louise 1.1**（`louise/zh`，`zero-shot-instruct`，语速 1.1，上面三种语气指令）。这九条 1.1 的试音，整片配音直接用（读的字和语气没变的话）。
